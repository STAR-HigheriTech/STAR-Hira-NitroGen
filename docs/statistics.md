## Usage statistics collection in Hira

By default, Hira sends some statistics about how it's used. Currently,
these include:

- Your operating system and computer language
- When you installed Hira
- The version of Hira that you're using
- How often you use certain features in Hira
- An anonymous ID representing your installation of Hira

Collecting this data allows us to prioritize which devices and operating systems
we test and which features we work on.

Hira does not send:

- Anything that can be used to personally identify you
- Any browsing history, passwords, or other data stored locally in
  Hira

If you want to opt-out of statistics collection, you can do so by going to the
preferences page within Hira and de-selecting "send usage statistics".
