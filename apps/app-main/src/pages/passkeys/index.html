如何使用

  1. 在支持 Passkey 的网站点击“使用 Passkey 登录”。
  2. 由 Windows Hello、Touch ID 或安全密钥完成本机验证。
  3. 出现多个账户时，在 Hira 的选择窗口里选中要使用的身份。

设备绑定 Passkey 不会上传到 Hira。跨设备同步由操作系统或站点自己的账户体系负责。
