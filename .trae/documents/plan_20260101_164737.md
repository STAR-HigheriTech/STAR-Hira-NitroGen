# UI 迁移计划：将 Zen 浏览器样式应用到 Min 浏览器

## 目标

将 HigheriBrowser-Zen 的 HTML/CSS UI 设计整合到 Min 浏览器的现有结构中，保持 Min
的所有功能 API 和接口不变。

## 主要修改文件

### 1. **index.html** - 主页面结构

**修改内容：**

- 采用 Zen 的 macOS 风格标题栏设计（交通灯按钮）

- 整合 Zen 的导航控制按钮样式

- 保持 Min 现有的 navbar 结构

- 采用 Zen 的标签页栏设计

- 整合 Zen 的地址栏和功能按钮布局

### 2. **css/base.css** - 基础样式

**修改内容：**

- 采用 Zen 的 CSS 变量系统（`:root` 定义的色彩方案）

- 添加暗色模式支持（`body.dark`）

- 整合 Zen 的全局样式规则

### 3. **css/tabBar.css** - 标签页样式

**修改内容：**

- 采用 Zen 的标签页设计风格

- 整合 Zen 的 `.tab` 样式（圆角、阴影、动画效果）

- 添加 Zen 的标签页交互效果

### 4. **css/searchbar.css** - 搜索栏样式

**修改内容：**

- 采用 Zen 的地址栏设计

- 整合 Zen 的搜索框样式和动画效果

### 5. **css/webviews.css** - 网页视图样式

**修改内容：**

- 采用 Zen 的主内容区域布局

- 调整高度计算以适应新的标题栏

## 设计风格迁移

### 保留的 Min 功能：

- ✅ 所有现有的 ID 和类名（保持 JavaScript 兼容性）

- ✅ 窗口控制按钮（Windows/Linux 平台）

- ✅ 所有导航功能

- ✅ 标签页管理

- ✅ 搜索栏功能

- ✅ 快捷键和交互

### 采用的 Zen 设计：

- 🎨 macOS 风格交通灯按钮

- 🎨 毛玻璃效果（backdrop-filter）

- 🎨 圆角设计

- 🎨 柔和阴影

- 🎨 暗色模式支持

- 🎨 平滑动画过渡

- 🎨 现代化的按钮样式

## 实施步骤

1. **分析现有结构** - 了解 Min 的 DOM 结构
2. **修改 base.css** - 应用 Zen 的基础样式变量
3. **修改 tabBar.css** - 采用 Zen 的标签页设计
4. **修改 searchbar.css** - 采用 Zen 的搜索栏样式
5. **修改 webviews.css** - 调整内容区域布局
6. **修改 index.html** - 整合 Zen 的 UI 元素

## 注意事项

- ⚠️ 保持所有现有 JavaScript API 兼容性

- ⚠️ 不修改任何功能逻辑

- ⚠️ 只修改视觉样式和布局
